## 一、Claude：大语言模型
* **Claude：** 美国人工智能初创公司Anthropic发布的大型语言模型家族，拥有高级推理、视觉分析、代码生成、多语言处理、多模态等能力。
* **Anthropic公司：** 前OpenAI研发副总裁达里奥·阿莫迪和安全政策副总裁丹妮拉·阿莫迪（兄妹）与包括曾经领导GPT-3开发的Tom Brown在内的其他5名OpenAI员工一起离职，在2021年创立了Anthropic公司。
* **Claude产品目标：** Claude非常强调安全性与合规性，遵循一套伦理和行为原则，旨在避免性别歧视、种族主义和有害输出，以及避免帮助人类从事非法或不道德活动。此外，Anthropic还有专门的安全评估和监控团队来监控违反原则的用例。
* **Anthropic公司代表产品：** 
    * 2025.5.22推出Claude 4系列（含Haiku、Sonnet、Opus版本）
    * 2025.10.16推出Claude Skills智能体功能

## 二、OpenClaw：AI Agent
* **创建：** OpenClaw的创始人Peter Steinberger在2024年11月创建其原型。
* **更名：** 最初名“Clawdbot”，因涉及商标风险且“Bot”一词缺乏自主性，后因社区中一个AI实例展现出“脾气”（自主写博文争论），遂更名为更独立、开源的OpenClaw。
* **核心架构：** 由Gateway（网关）、Agent（智能体）、Skills（技能）和Memory（记忆）构成，能运行在用户本地设备上，并通过WhatsApp、Telegram、Discord等聊天App与之互动。
    * Gateway（网关）是整个系统的神经中枢，连接着各类聊天平台，打通了智能体与外部世界交互的通道，确保指令与反馈能被实时传递；
    * Agent（智能体）驱动系统的思考过程，接入了模型负责处理复杂的上下文记忆与逻辑推理；
    * Skills（技能）赋予了它“手脚”，使其具备了网页调研、浏览器自动化乃至访问邮箱的实际执行力；
    * Memory（记忆）负责将所有对话与偏好以真实文件的形式持久化保存。
* 打造一人公司实战思路：
    * 大脑（Brain）： 在 config 中接入 MiniMax 或 GLM4.7。利用国内 API 的低成本优势（每天 1500 万 Token 随便跑），让它拥有顶级的逻辑规划能力。
    * 躯干（Body）： 在 Termux 中部署 OpenClaw。
    * 手脚（Hands）： 赋予它操作 curl、git 和文件系统的权限。
## 三、Agent进化历程
1.史前时代的野心与破产：AutoGPT的死循环 (2023)
    * 无限递归：经常陷入逻辑死循环，反复打开同一个网页，反复报错。
    * Token焚烧炉：很多开发者一觉醒来，发现任务没完成，OpenAI 的 API 账单却烧了几百美元。
    * 落地为零： 它展示了“自主 Agent”的可能性，但几乎没有任何实际产出能力。
2.工具人的觉醒：OpenInterpreter 的命令行革命 (2024)
    * OpenInterpreter（开放解释器）出现了。它放弃了“宏大目标”，专注于解决一个具体问题：让 LLM 真的去跑代码。它通过在本地建立一个沙盒，允许 LLM 将自然语言（“把这堆视频转成 GIF”）转化为 Python 脚本并在终端执行。这通过了图灵测试的“实操版”。
    * 局限性： 它是无状态、无记忆的，像是一个随叫随到的CLI工具，用完即走，只是一个更聪明的 Shell。
3. 最终形态：OpenClaw 的“寄生”哲学 (2025-2026)
    * OpenClaw解决了前两者的致命缺陷，继承了OpenInterpreter的执行力（直接操作 OS）。它修复了AutoGPT的多动症（引入了更严格的规划层）。
    * 核心突破：Daemon（守护进程化）。OpenClaw 不再是一个软件，它是一个系统服务。它可以像 Linux 的 cron job 一样，潜伏在你的 Termux 后台。它拥有了“时间感”——它可以每 10 分钟醒来一次检查你的邮件，或者每天凌晨 3 点自动打包你的代码并推送到服务器。如果说 AutoGPT 是为了演示，OpenInterpreter 是为了辅助，那么 OpenClaw 就是为了共生。它真正成为了你操作系统里的“第二大脑”。
    * OpenClaw像个活人:它有**心跳（heartbeat），** 有一个Cron Job（定时任务）机制；**本地主义** 它没有 App，它就寄生在你的 WhatsApp、Slack 或者 Termux 终端里。它直接读写你硬盘里的 Markdown 文件作为记忆。这不仅安全，更意味着它的记忆是永久且物理存在的，不是云端数据库里的一行代码。
